# qlyyz.xyz

樱花动漫 YHDM APP



## 项目说明
本软件是对开源项目 Kazumi 的二次定制改造作品，不存在完全独立编写的底层源码，所有基础项目架构继承原开源仓库。
本人在此基础上完成以下自定义开发工作：

- 前端页面全套样式重写，全新UI视觉；
- 对接第三方播放资源接口，开发内置选集网页播放器；
- Live2D看板娘开关、底部导航栏、番剧卡片双按钮定制；
- Bangumi 番剧接口分页、搜索逻辑修复与优化；
- 移动端响应式布局适配。

## 支持平台
Android 10 及以上版本

## 功能一览
- 番剧首页按播出时间排序加载；
- 标签、名称快速检索番剧；
- 番剧详情：评分、放送信息、角色、制作人员、作品简介；
- 两种观看渠道，网页端内置播放器支持集数切换；
- Live2D 交互式看板娘组件。
