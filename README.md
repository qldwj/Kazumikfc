## 项目说明
本项目是基于开源项目 [Kazumi](https://github.com/Predidit/Kazumi) 二次定制的樱花动漫 YHDM ，并非从零开发，底层架构与基础能力继承自原仓库。

## 功能

- 番剧首页按播出时间排序
- 标签、名称快速搜索番剧
- 番剧详情：评分、放送信息、角色、制作人员、简介
- 内置网页播放器，支持集数切换
- 第三方播放源，可切换线路
- 第三方账号登录，同步追番与收藏
- 追番进度记录
- 收藏 / 追番列表管理
- 弹幕
- 倍速播放
- 下载缓存
- 深色模式
- 移动端响应式布局
-以及更多功能，提供尽可能简单且舒适的追番体验。
## 支持平台
Android 10 及以上版本
